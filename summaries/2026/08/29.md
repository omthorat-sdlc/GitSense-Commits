*   **Image Compositing:** A `composite` function is responsible for drawing the marks onto a canvas using the `body-map.png` image and returning a data-URL, ensuring that the marked body can be preserved exactly as entered.
*   **Component Props:** The component accepts `value`, `onChange`, `options` (for region labels), and `readOnly` props.

The overall pattern is to provide a highly interactive visual input mechanism for anatomical locations, with precise coordinate mapping and robust data output suitable for documentation.
